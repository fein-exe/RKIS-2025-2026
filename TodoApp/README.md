# TodoList Console Application

Полнофункциональное консольное приложение для управления списком задач с поддержкой многопользовательского режима, отката/повтора операций, поиска, параллельных загрузок, клиент-серверной синхронизации и хранения данных в SQLite.

## Функциональность

### Основные возможности

- **Управление профилями пользователей**
  - Регистрация новых профилей с логином и паролем
  - Вход в существующий профиль
  - Выход из профиля

- **Управление задачами**
  - Добавление задач (однострочный и многострочный режимы)
  - Просмотр списка задач с различными параметрами (индексы, статусы, даты)
  - Чтение полного текста задачи
  - Обновление текста задачи
  - Удаление задачи
  - Изменение статуса задачи

- **Статусы задач**
  - NotStarted (не начато)
  - InProgress (в процессе)
  - Completed (выполнено)
  - Postponed (отложено)
  - Failed (провалено)

- **Поиск задач (search)**
  - Поиск по части строки (`--contains`)
  - Поиск по началу строки (`--starts-with`)
  - Поиск по концу строки (`--ends-with`)
  - Фильтрация по диапазону дат (`--from` / `--to`)
  - Фильтрация по статусу (`--status`)
  - Сортировка результатов по тексту или дате (`--sort`)
  - Сортировка по убыванию (`--desc`)
  - Ограничение количества результатов (`--top`)

- **Параллельные загрузки (load)**
  - Демонстрация асинхронности с прогресс-барами
  - Одновременное обновление нескольких прогресс-баров

- **Клиент-серверная синхронизация**
  - Отправка данных на сервер (`sync --push`)
  - Получение данных с сервера (`sync --pull`)

- **Расширенные функции**
  - Отмена последней операции (Undo)
  - Повтор отменённой операции (Redo)
  - Хранение данных в SQLite через Entity Framework Core
  - Шифрование данных (AES) для файлового хранилища
  - Загрузка данных при запуске

## Команды
help - показать справку
register <логин> <пароль> <имя> <фамилия> <год> - регистрация
login <логин> <пароль> - вход в профиль
profile [-o] - показать профиль / выйти из профиля
add "текст" - добавить задачу
add -m/--multiline - добавить задачу в многострочном режиме
view [-i] [-s] [-d] [-a] - показать задачи
-i --index - показать индекс
-s --status - показать статус
-d --date - показать дату изменения
-a --all - показать всё
read <idx> - показать полный текст задачи
status <idx> <статус> - изменить статус задачи
update <idx> "новый текст" - обновить текст задачи
delete <idx> - удалить задачу
undo - отменить последнее действие
redo - повторить отменённое действие
search --contains <текст> - задачи, содержащие текст
search --starts-with <текст> - задачи, начинающиеся с текста
search --ends-with <текст> - задачи, заканчивающиеся текстом
search --from <yyyy-MM-dd> - задачи после указанной даты
search --to <yyyy-MM-dd> - задачи до указанной даты
search --status <статус> - задачи с указанным статусом
search --sort <text|date> - сортировка результатов
search --desc - сортировка по убыванию
search --top <n> - показать первые N задач
load <кол-во> <размер> - параллельная загрузка файлов
sync --pull - получить данные с сервера
sync --push - отправить данные на сервер
exit - выход из программы

## Хранение данных

### SQLite (основное хранилище)

Файл: `todos.db`

**Схема базы данных:**

| Таблица | Поля |
|---------|------|
| Profiles | Id (PK), Login, Password, FirstName, LastName, BirthYear |
| TodoItems | Id (PK), Text, Status, LastUpdate, ProfileId (FK) |

### Файловое хранилище (альтернативное)

**Профили:** `data/profiles.dat` (зашифрованный AES)
**Задачи:** `data/todos_{UserId}.dat` (зашифрованный AES)

### Шифрование

- Алгоритм: AES
- Ключ и IV сохраняются в `data/encryption.key` и `data/encryption.iv`

## Обработка ошибок

Все ошибки обрабатываются через пользовательские исключения:

```csharp
try {
    var command = CommandParser.Parse(input);
    command.Execute();
}
catch (TaskNotFoundException ex) {
    Console.WriteLine($"Ошибка задачи: {ex.Message}");
}
catch (AuthenticationException ex) {
    Console.WriteLine($"Ошибка авторизации: {ex.Message}");
}
catch (InvalidCommandException ex) {
    Console.WriteLine($"Ошибка команды: {ex.Message}");
}
catch (InvalidArgumentException ex) {
    Console.WriteLine($"Ошибка аргументов: {ex.Message}");
}
catch (DuplicateLoginException ex) {
    Console.WriteLine($"Ошибка регистрации: {ex.Message}");
}
